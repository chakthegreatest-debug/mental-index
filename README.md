# Mental Index — версия 3

Рабочая страница: [dashboard-v3.html](dashboard-v3.html).
Корень проекта перенаправляет на неё. Тексты, данные, оформление и код версии 3 сохранены без изменений.

## Запуск на Mac

Из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/`. Сборка, npm и внешние API не требуются.

## Права и данные

Euclid Circular A — коммерческий шрифт. Он есть в assets/fonts и встроен в HTML версии 3.
Исходный README требует проверить веб-лицензию. Документ о лицензии в исходниках не найден.
Удаление только assets/fonts не удаляет шрифт из HTML.
Общая лицензия на исходный проект в репозитории также не обнаружена.
Новые лицензии не назначены; публичное размещение не выполняется.

Версия 3 содержит агрегированные результаты исследования. Форм ввода и отправки данных в ней нет.
Проверка HTML и подключённых скриптов не выявила вызовов fetch, XMLHttpRequest, sendBeacon или WebSocket.
Тексты и цифры не проходили новую содержательную проверку и сохранены как в источнике.
